RÉSIDENCE DS — Site web responsive (2 pages)

FICHIERS
- index.html : page d'accueil et présentation
- reservation.html : formulaire de demande de réservation
- css/style.css : styles, mise en page responsive, menu mobile
- js/main.js : menu hamburger, validation des dates et lien WhatsApp

OUVRIR LE SITE
1. Décompressez residence_ds_site.zip.
2. Ouvrez index.html dans votre navigateur.
3. Cliquez sur « Réservation » pour tester le formulaire.
